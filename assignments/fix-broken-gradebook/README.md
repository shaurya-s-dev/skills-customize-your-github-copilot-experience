# 📘 Assignment: Fix the Broken Gradebook

## 🎯 Objective

Students will debug a small Python command-line program that reads a CSV gradebook and reports student scores. They will practice tracing bugs, correcting file I/O issues, and making output reliable and user-friendly.

## 📝 Tasks

### 🛠️ Repair the Gradebook Loader

#### Description
Fix the starter program so it can open the gradebook file, read the student records, and print the names and scores without crashing.

#### Requirements
Completed program should:

- Open the provided CSV file successfully
- Read every student record from the file
- Print each student name with their score


### 🛠️ Calculate Correct Summary Results

#### Description
Update the program so it calculates accurate summary statistics for the class and handles missing or invalid data safely.

#### Requirements
Completed program should:

- Calculate the class average score correctly
- Show the highest and lowest score in the gradebook
- Skip invalid rows or report them without stopping the program
